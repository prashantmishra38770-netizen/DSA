# Data Structures and Algorithms (DSA) in C

This repository contains my Data Structures and Algorithms (DSA) programs written in C. I am learning DSA as part of my B.Tech  curriculum at AKTU and regularly updating this repository with new programs.

## Topics Covered

- Arrays
-Pointer
- Searching
- Sorting
- Functions
- Strings
- Linked List
- Stack
- Queue
- Trees
- Graphs
- Recursion
- Dynamic Memory Allocation

## Language

- C

## IDE Used

- Visual Studio Code

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/prashantmishra38770-netizen/DSA.git
   ```

2. Open the project in Visual Studio Code.

3. Compile using GCC:
   ```bash
   gcc filename.c -o output
   ```

4. Run:
   ```bash
   ./output
   ```
